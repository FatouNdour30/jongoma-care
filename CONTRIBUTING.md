# Contribuer à Jongoma Care

Merci de votre intérêt.

- Ouvrez une issue avant un changement important pour en discuter.
- Une pull request par sujet, avec une description claire et le numéro d'exigence concerné (F-xx) si applicable.
- Vérifiez que `npm run lint` et `npm run build` passent.
- Tout contenu de santé doit être validé par un professionnel habilité avant d'être fusionné.
- N'ajoutez jamais de données réelles, même anonymisées, dans le dépôt.

Les contributions sont publiées sous licence Apache-2.0.
