# Politique de sécurité

Jongoma Care traite, en production, des données de santé sensibles. Si vous découvrez une vulnérabilité :

1. Ne l'exposez pas publiquement (pas d'issue publique).
2. Écrivez à [adresse de sécurité à définir] avec une description et les étapes de reproduction.
3. Nous accusons réception sous 5 jours ouvrés et publions un correctif dès que possible.

Ce dépôt ne doit jamais contenir de données réelles, de secrets, de clés API ou de configurations privées.
